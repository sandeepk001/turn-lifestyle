# TURN Lifestyle - Premium Product Catalog

A high-end, minimalist product showcase website for TURN (turn-lifestyle), a premium apparel brand.

## Features

- 🎨 Luxury minimalist design with floating product images
- 🔍 Full-screen overlay search with real-time filtering
- 📱 Fully responsive (mobile-first design)
- 💬 WhatsApp inquiry integration
- 🎠 Infinite hero carousel
- 🏷️ Category filtering (All, Night Pants, T-Shirts, Trousers, etc.)
- ✨ Glassmorphism effects and smooth animations

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide-React
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
├── app/              # Next.js App Router pages
├── components/       # React components
├── data/            # Product data and constants
└── styles/          # Global styles
```

## Adding Products

Edit `src/data/products.ts` to add or modify products. Each product should include:
- id, name, category, price, rating
- description, colors, mainImg, gallery
